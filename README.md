# EpubReader 简易阅读器

一个基于 PyQt 的轻量级电子书阅读器，支持 TXT 与 EPUB，提供按行对齐翻页、阅读样式调节、自适应识别和快捷键自定义等功能。

## 下载
[📥 点击下载最新版 (V2.0) - 无需安装，解压即用](https://github.com/hou720616/EpubReader/releases/tag/V2.0)

## 功能特性
- 支持加载 `.txt` 与 `.epub` 文件
- 自动分章：对超长文本按每 5 万字符切片以降低卡顿
- 章节跳转：从右键菜单快速选择章节
- 翻页与滚动：
  - 按行对齐翻页，避免累积误差
  - 滚轮按行滚动（步长为 3 行）
  - 键盘：默认 A 上一页，D 下一页（可自定义）
  - 鼠标：窗口左半区上一页，右半区下一页；窗口边缘拖动调整大小
- 样式控制：字体、字体颜色、字体透明度、背景色、背景透明度
- 自适应识别：可识别并应用字体颜色、背景色、字号（支持按项勾选）
- 快捷键设置：可在首页配置“上一页/下一页/隐藏显示/关闭窗口”
- 防截屏：可在阅读窗口右键菜单开关防截图
- 无边框窗口与边缘尺寸调整
- 进度记忆：按文件路径记录章节索引与滚动位置（校验 mtime/size）
- 最近文件记忆：配置文件中保存上次打开路径

## 常用操作
- 右键菜单：打开文件、章节跳转、上一页/下一页、自适应识别、返回首页、防截屏、退出
- 默认键盘：A 上一页；D 下一页；Alt+V 隐藏/显示；Alt+Q 关闭窗口
- 鼠标：
  - 左半区单击上一页，右半区单击下一页
  - 边缘拖动进行无边框窗口的尺寸调整
  - 滚轮按行滚动
