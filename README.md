# EpubReader 简易阅读器

一个基于 PyQt 的轻量级电子书阅读器，支持 TXT 与 EPUB，提供按行对齐翻页、阅读样式调节、自适应识别和快捷键自定义等功能。

## 功能特性
- 支持加载 `.txt` 与 `.epub` 文件
- 自动分章：对超长文本按每 5 万字符切片，降低渲染卡顿
- 章节跳转：阅读窗口右键菜单可快速选择章节
- 双入口阅读设置：首页与阅读窗口右键菜单均可打开同一设置面板
- 样式控制：字体、字号、字体颜色、字体透明度、背景色、背景透明度、字距、行距
- 自适应识别：
  - 可识别并应用字体颜色、背景色、字号、字距、行距（支持按项勾选）
  - 识别字号使用像素高度估算并换算为点数（pt），兼容高 DPI 场景
- 翻页与滚动：
  - 按行对齐翻页，避免累积误差
  - 滚轮按行滚动（步长为 3 行）
  - 鼠标窗口左半区上一页，右半区下一页
- 快捷键设置：可在首页配置“上一页/下一页/隐藏显示/关闭窗口”
- 防截屏：可在阅读窗口右键菜单开关
- 无边框窗口与边缘尺寸调整
- 阅读进度记忆：按文件路径记录章节与滚动位置（校验 mtime/size）
- 最近文件与继续阅读：自动维护最近列表与上次打开路径

## 常用操作
- 首页：
  - 打开本地书籍
  - 继续阅读
  - 阅读设置（支持自适应识别与快捷键配置）
- 阅读窗口右键菜单：
  - 打开文件、章节跳转、阅读设置、返回首页、防截屏、退出
- 默认键盘：A 上一页；D 下一页；Alt+V 隐藏/显示；Alt+Esc 关闭窗口（默认额外支持 Alt+Q 关闭兜底）
- 鼠标：
  - 左半区单击上一页，右半区单击下一页
  - 边缘拖动进行无边框窗口的尺寸调整
  - 滚轮按行滚动
